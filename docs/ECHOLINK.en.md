# EchoLink

The WebUI integrates EchoLink directly into the SvxLink interface.

## Your node

The WebUI shows:

- your EchoLink callsign
- Node ID
- online state
- EchoLink module state
- current connections

## Activating EchoLink

The EchoLink module can be activated and deactivated directly from the WebUI.

## Current connections

Active connections are shown with callsign and connection duration.

Incoming and outgoing connections are distinguished.

Existing connections can be disconnected directly.

## Search

You can search for:

- callsign
- EchoLink Node ID

The WebUI then shows whether the node is currently available.

### ONLINE

The node is currently logged in and can be connected.

### BUSY

The node is logged in but is not currently accepting a normal new connection.

### OFFLINE

The node is registered but is not currently logged in.

## Favourites

Frequently used EchoLink nodes can be saved as favourites.

Their current state is shown automatically.

Online favourites can be connected directly from the list.

## History

The WebUI stores new EchoLink connections in a history.

Displayed information includes:

- callsign
- direction
- time
- duration

History starts from the point where the WebUI is installed and recording is active.
